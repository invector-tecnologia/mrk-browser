Act as a Senior Software Engineer and Architect specializing in Rust. Build the "mrk-browser" project, a modular mini-browser in Rust with a hybrid architecture (GUI + TUI) and a rendering pipeline focused on content conversion.

### 1. ARCHITECTURE AND INTERFACE REQUIREMENTS
- **Shared Core (`mrk-core`):** Create an internal Rust library to manage the network layer (reqwest/tokio) and the data parsing pipeline.
- **Graphical Interface (GUI):** Use Tauri to render the default desktop interface, exposing a native address bar and a viewing panel.
- **Terminal Interface (TUI):** Use the Ratatui framework to provide a full experience directly in the terminal.
- **Dispatch Mechanism (CLI/Flags):** The final binary must accept the `--tui` flag to start the Ratatui interface in the active terminal. When run without flags, it must open the Tauri graphical window.

### 2. PARSING PIPELINE (HTML -> MDX)
- Capture the raw HTML string from the HTTP response.
- Build a parser (using crates such as `tl`, `html5ever` or `scraper`) that sanitizes the structural tags and converts the content directly to the MDX format (structured Markdown with support for inline JSX blocks/components).
- In the GUI (Tauri), the MDX must be rendered with a suitable web component. In the TUI (Ratatui), the structured Markdown tags must be converted into text styles (`ratatui::text::Span`) with colors and indentation, ignoring or isolating complex JSX blocks.

### 3. DEPLOYMENT AND PACKAGING (OMARCHY/ARCH LINUX)
- The project must include a clean, idiomatic Rust build manifest (`Cargo.toml`).
- For distribution on Omarchy Linux, include a standard Arch Linux `PKGBUILD` file that builds the project in `--release` mode, installs the final binary at `/usr/bin/mrk-browser`, and provides a `.desktop` file for integration with the graphical desktop application launcher.
- Make sure that uninstalling with `pacman -R mrk-browser` cleanly removes all artifacts.

Generate the architecture documentation, the detailed PRD, the workspace directory structure and the fully implemented Rust source code, without defensive unwraps and handling errors through structured Result types.

## Implementation approach

To implement the 'mrk_browser', we will leverage Rust's modularity to create a hybrid GUI and TUI application. The core functionality will be divided into several modules, including a network library for handling HTTP requests using reqwest/tokio, a parser for sanitizing HTML tags and converting them to MDX format, and UI libraries for both graphical (using Tauri) and textual user interfaces (using Ratatui).

## Data structures and interfaces


classDiagram
    class MRKBrowser {
        -gui_handler GUIHandler
        -tui_handler TUIHandler
        +run() void
    }
    class GUIHandler {
        -browser Browser
        +display_content(content: String) void
        +update_address_bar(url: String) void
    }
    class TUIHandler {
        -reader Reader
        +render_content(content: String) void
    }
    class Browser {
        -tabs Tab[]
        +navigate(url: String) void
        +add_tab() Tab
    }
    class Tab {
        -url URL
        -content Content
        +load_content(html: String) void
    }
    class URL {
        -address String
        +get_address() String
    }
    class Content {
        -format Format
        +convert_to_mdx() MDXContent
    }
    class Format {
        -type String
        +is_valid() bool
    }
    class MDXContent {
        -content String
        +render() void
    }

## Program call flow


sequenceDiagram
    participant M as MRKBrowser
    participant GH as GUIHandler
    participant BH as Browser
    participant T as TUIHandler
    participant R as Reader
    M->>M: run()
    M->>GH: display_content(content)
    GH->>BH: navigate(url)
    BH-->>GH: return tab with content
    GH->>GH: update_address_bar(url)
    M->>T: render_content(content)
    T->>R: read()
    R-->>T: return rendered content
